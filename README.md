A [make.fun](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3) bounty entry: one sentence, at most 200 characters, that makes a small everyday moment strange and new.

## The entry

> The escalator's handrail ran a fraction faster than the steps, and my hand kept arriving before I did.

## How it works

`main.ts` writes that single sentence to `/output/entry.txt` (102 characters, valid UTF-8, one sentence, no trailing newline) and validates it first: 1–200 characters, not only whitespace, no leading or trailing whitespace, exactly one sentence-ending mark.

Run it with Node 22.18 or later:

```sh
node main.ts
```
